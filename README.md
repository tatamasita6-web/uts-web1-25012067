## Deskripsi Project
Aplikasi pemesanan makanan dan minuman kantin menggunakan PHP Native.

## Fitur
- Menampilkan daftar menu kantin.
- Mencari menu menggunakan metode GET.
- Memvalidasi input jumlah pesanan menggunakan POST.
- Menyimpan keranjang belanja menggunakan session.
- Menghitung subtotal dan diskon.
- Menampilkan pesan menggunakan flash message dan redirect.
- Menyimpan kategori menggunakan cookie.

## Teknologi
- PHP Native
- HTML
- CSS
- Session dan Cookie

## Cara Menjalankan
1. Simpan folder project di dalam `htdocs`.
2. Jalankan Apache melalui XAMPP.
3. Buka `http://localhost/web1/uts-web1-25012067/` di browser.
